# ActionPane Component (`src/components/ActionPane/index.tsx`)

## Purpose

The `ActionPane.tsx` component displays available interactions and system actions. Overworld navigation belongs to the cell-native World Map, not compass or named-exit buttons. See the [World Map navigation boundary](../../../docs/architecture/domains/world-map.md#named-exit-navigation-retirement) and [location-data guidance](../../data/world/LOCATIONS.README.md#named-exit-navigation). Navigation claims were checked against source on 2026-10-10 (WF-G318); the remaining component details below are not a fresh full-component or gameplay verification.

*   Interacting with NPCs (e.g., "Talk to [NPC Name]").
*   Interacting with items (e.g., "Take [Item Name]").
*   Showing authored interactable features without turning `Location.exits` into movement buttons.
*   Opening the World Map. The legacy rectangular Submap and 2D village routes are retired; the map's current cell-native drill-down is a different system.
*   Asking the Oracle a question.
*   Displaying custom, context-aware actions generated by the Gemini AI after a "Look Around" action (if any).
*   Managing rest actions (Short Rest and Long Rest), including Hit Dice spending via a modal with per-character healing previews.
*   Saving the game.
*   Returning to the main menu (with a save prompt).
*   **Animations**: Action buttons are animated using `framer-motion` to provide satisfying "pop-in" feedback on appearance.

## Props

*   **`currentLocation: Location`**:
    *   **Type**: `Location` (from `src/types/index.ts`)
    *   **Purpose**: The character's current location object. Used for interactions, not named-exit travel.
    *   **Required**: Yes

*   **`npcsInLocation: NPC[]`**:
    *   **Type**: Array of `NPC` objects (from `src/types/index.ts`)
    *   **Purpose**: A list of NPCs currently present in the `currentLocation`.
    *   **Required**: Yes

*   **`itemsInLocation: Item[]`**:
    *   **Type**: Array of `Item` objects (from `src/types/index.ts`)
    *   **Purpose**: A list of items currently available to be taken from the `currentLocation`.
    *   **Required**: Yes

*   **`party: PlayerCharacter[]`**:
    *   **Type**: Array of `PlayerCharacter` objects (from `src/types.ts`)
    *   **Purpose**: Provides the party roster so the Short Rest modal can show Hit Dice per character.
    *   **Required**: Yes

*   **`onAction: (action: Action) => void`**:
    *   **Type**: Function
    *   **Purpose**: A callback function invoked when an action button is clicked. It passes the corresponding `Action` object.
    *   **Required**: Yes

*   **`disabled: boolean`**:
    *   **Type**: `boolean`
    *   **Purpose**: If `true`, all action buttons in this pane are disabled. This is typically used when another action is being processed or the game is in a loading state.
    *   **Required**: Yes

*   **`geminiGeneratedActions: Action[] | null`**:
    *   **Type**: Array of `Action` objects or `null`
    *   **Purpose**: A list of custom actions suggested by the Gemini AI, usually after a "Look Around" action. If `null` or empty, this section is not displayed.
    *   **Required**: Yes

## State Management (Internal)

*   **`isOracleInputVisible: boolean`**: Controls the visibility of the input field for asking the Oracle a question.
*   **`oracleQuery: string`**: Stores the text entered by the player for their Oracle query.
*   **`isRestModalOpen: boolean`**: Toggles the Short Rest modal used to spend Hit Dice.

## Core Functionality

1.  **Dynamic Action Generation**:
    *   **NPC Interaction**: Creates "Talk to [NPC Name]" buttons for each NPC in `npcsInLocation`.
    *   **Item Interaction**: Creates "Take [Item Name]" buttons for each item in `itemsInLocation`.
    *   **Navigation Boundary**: Does not create direction or special-exit buttons from `currentLocation.exits`. Town entry uses Enter 3D on the World Map.

2.  **Oracle Interaction**:
    *   "Ask the Oracle" button toggles visibility of an input field.
    *   Player can type a query and submit it, which calls `onAction` with an `ask_oracle` type.

3.  **Gemini Custom Actions**:
    *   If `geminiGeneratedActions` is provided and not empty, this section is displayed with buttons for each suggested action. These actions typically have a `type` of `gemini_custom_action`.

4.  **System Actions**:
    *   Buttons for "Save Game" and "Main Menu" (or "Dev Menu" in dev mode).
    *   A rest section that opens the Short Rest modal or dispatches Long Rest directly.

5.  **Button Styling**:
    *   Uses a shared `ActionButton` sub-component for consistent styling.
    *   Different action types (e.g., save, main menu, dev menu, Gemini actions, Oracle) can have distinct button colors.

## Layout
The pane has a main title "Interactions & System".
World Map access is a system action; the retired rectangular Submap toggle is not a current route.
Oracle, Save, and Main Menu/Dev Menu buttons are grouped.
Gemini-suggested actions and general NPC/item actions are displayed in separate, clearly headed sections if available.
Overworld navigation is separate from this pane and uses the World Map.

## Data Dependencies
*   `src/types/index.ts`: For `Location`, `Action`, `NPC`, `Item` types.
*   Named-exit movement and legacy grid-adjacency village detection are not generated here. Retained location data is not an edit grant to recreate the old routes.

## Styling
*   Uses Tailwind CSS for styling of the pane and buttons.
*   Actions are grouped logically for better usability.

## Accessibility
*   All buttons have `aria-label` attributes.
*   The "Ask the Oracle" input field is properly labeled.
*   Buttons are disabled when appropriate, providing visual feedback.
*   Headings are used to structure different action sections.
